# SS4 Whispering Mist — strategy base

On the site: `/ss4/` (Mistville sheet, in 7 languages) and its card on the event list. Running the site: see the [root README](../../README.md).

| File | What it is |
|---|---|
| [CLAUDE.md](CLAUDE.md) | Maintenance context (sources, where to make changes, pitfalls). General base in `../README.md`. |
| [MISTVILLE_GUIDE.md](MISTVILLE_GUIDE.md) | Base document: rules, months and rewards, strategy, sources, gaps. Its frontmatter is the event card. |
| [REFERENCE.md](REFERENCE.md) | Old Stuff, tiles, Trader goods and Folklore cells with EN/CN names and values (tlidb, current client). |
| [CHANGELOG.md](CHANGELOG.md) | What changed and when. |
| `banner.webp` | Official season key art, background of the event card. |
| `images/` | Official SS4 site screenshots + `INDEX.md` (transcriptions and sources). |
| `art/` | Game icons drawn on the sheet + `SOURCES.md` (generated by `scripts/game_art.py`). |
| `credits.json` | Creators credited in the sheet's "Method & credits" dialog (none: text sources only). |
| `scripts/game_art.py` | Downloads and trims the game icons (by hand, needs Pillow). |
